# Devkart

We build custom software, multi-tenant SaaS platforms and MVPs — and run two products of
our own: [SuperApp](https://www.superapphq.com) and [Supaorder](https://www.supaorder.com).

## Open-source plugins

| Package | What it does |
|---|---|
| capacitor-star-printer | Star Micronics printers (Bluetooth, USB, LAN) via StarXpand |
| capacitor-tcp-print | Raw TCP (port 9100) printing to network printers |
| capacitor-usb-print | USB receipt printers on Android |
| capacitor-thermal-printer | Bluetooth thermal printers, with iOS Swift Package Manager support (fork of Malik12tree/capacitor-thermal-printer) |
